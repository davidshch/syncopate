# Syncopate 🎶

Way for two people to jam in a browser. Shared metronome, clocks in sync, audio P2P. Chrome for now.

## Run

Node 20+ and [pnpm](https://pnpm.io/).

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in two Chrome windows. Enable audio on both (use headphones — echo cancellation is off), then start the metronome.
